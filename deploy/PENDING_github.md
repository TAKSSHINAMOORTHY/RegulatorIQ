# Pending GitHub Actions Secret Setup

To enable automated CI/CD deployment on git push tags (`v*`), configure the following repository secrets via the GitHub Web UI or GitHub CLI (`gh secret set <NAME>`):

- `GHCR_TOKEN`: GitHub Container Registry personal access token (with `write:packages` scope)
- `WARMUP_TOKEN`: Random 32-character secret generated by `python scripts/gen_token.py`
- `OCI_*`: Oracle Cloud credentials (if using OCI)
- `HF_TOKEN`: Hugging Face Space token (if using HF Space)
- `VERCEL_TOKEN`: Vercel token for frontend deploy
